# DK Synology Share Manager

Synology NAS의 **File Station 공유 링크를 Windows에서 한꺼번에 관리**하는 무료 프로그램입니다. DSM에 로그인하지 않고도 파일·폴더 공유 링크를 만들거나 변경하고, 필요 없어진 링크를 삭제할 수 있습니다.

## 다운로드 및 실행

1. [Releases](https://github.com/danhk0612/DK-Synology-Share-Manager/releases)에서 최신 `DKSynologyShareManager-...-win-x64.zip` 파일을 다운로드합니다.
2. 압축을 푼 뒤 `DKSynologyShareManager.exe`를 실행합니다. 별도 설치나 .NET 설치가 필요 없습니다.
3. **NAS 연결 / 변경**에서 DSM HTTPS 주소(예: `https://nas.example.com:5001`), 계정과 비밀번호를 입력합니다. 2단계 인증이 설정된 경우 OTP도 입력합니다.
4. NAS에 연결되면 기존 File Station 공유 링크가 목록에 표시됩니다.

**필요 환경:** Windows 10/11 64비트, Synology DSM의 File Station 사용 권한. 전체 계정의 공유 링크를 관리하려면 NAS 관리자 권한이 필요합니다. DSM 7.4.1 환경에서 주요 기능을 확인했습니다.

Windows SmartScreen 안내가 표시될 수 있습니다. 이 프로그램은 코드 서명 인증서를 사용하지 않습니다. 다운로드한 파일의 출처를 확인한 뒤 실행하세요.

## 주요 기능

- **공유 링크 관리:** 전체 계정 링크 목록, 검색, 계정·상태 필터, 시작·만료 기간 검색, 정렬, 페이지 이동
- **링크 생성:** NAS의 파일·폴더 선택, 비밀번호와 사용 기간 설정
- **링크 수정:** 목록 항목 더블클릭 또는 **설정 수정** 버튼으로 변경
- **링크 삭제:** 선택한 링크를 개별·여러 개 삭제. NAS의 원본 파일이나 폴더는 삭제하지 않습니다.
- **URL:** 공유 URL 복사 또는 브라우저에서 열기
- **NAS 탐색:** 폴더 트리, 아이콘 보기·자세히 보기, 파일명·크기·유형·생성/수정 시간, 지원되는 파일의 썸네일
- **로그인 편의:** 연결정보 저장 및 **이 PC에서 OTP 인증 기억**(DSM의 신뢰 장치 기능 지원 시)

## 사용 방법

**링크 만들기:** `링크 생성` → `NAS 탐색` → 공유할 파일/폴더 선택 → 비밀번호·시작일·만료일 설정 → 저장. 파일 선택 없이 선택 버튼을 누르면 현재 탐색 중인 폴더를 대상으로 합니다.

**수정/삭제:** 목록에서 링크 선택 → `설정 수정` 또는 `선택 삭제`. 기존 링크의 암호 원문은 확인할 수 없으며, 수정 화면에서 암호 유지·변경·해제를 선택할 수 있습니다.

**링크 찾기:** 상단 검색창·계정/상태/기간 필터를 활용합니다. 링크 자체의 생성·수정 일시는 NAS의 공개 Sharing API에서 제공하지 않으므로 표시하지 않습니다.

## 로그인 정보와 주의사항

- 연결정보 저장을 선택하면 실행 파일 폴더의 `SynologyShareManager.config.json`에 저장됩니다. 비밀번호와 신뢰 장치 ID는 **Windows 사용자별 DPAPI**로 암호화하며, OTP 코드는 저장하지 않습니다.
- 신뢰 장치로 로그인하더라도 DSM 정책·만료·장치 해제 시 OTP 입력이 다시 필요할 수 있습니다.
- NAS 주소에는 **HTTPS**를 사용하며 인증서 검증을 건너뛰지 않습니다. 신뢰할 수 있는 DSM 인증서를 준비하세요.
- 공유 링크를 삭제하면 그 URL을 통해 접근할 수 없게 됩니다. 기존 파일/폴더는 그대로 유지됩니다.
- Synology Drive 링크와 파일 요청 링크는 관리 대상이 아닙니다.
- NAS 파일 탐색에 표시되는 생성·수정 날짜는 **파일 자체의 날짜**이며 공유 링크 생성·수정 날짜가 아닙니다.
